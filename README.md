# Portfolio Forge

> Auto-generate a stunning GitHub README portfolio from your GitHub profile and repositories.

## What it does

- Reads your GitHub profile and repo data via GitHub API
- Generates a visually polished README.md with your stats, top repos, and activity
- Output goes to `generated-portfolio-README.md`

## Setup

1. Create a GitHub Personal Access Token (PAT) with `repo` scope
2. Add it to `index.js` or set as environment variable:
   ```bash
   export GITHUB_TOKEN=your_github_token_here
   ```
3. Update the `USERNAME` constant in `index.js` with your GitHub username

## Run



Output is written to `generated-portfolio-README.md`. Copy it to your GitHub profile README.
